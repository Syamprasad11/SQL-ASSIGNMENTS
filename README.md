# SQL Data Analysis Projects

This repository contains a collection of **data analysis projects created using SQL and MySQL Workbench**. Each project focuses on analyzing datasets, writing SQL queries, identifying patterns, and extracting meaningful insights from data.

## Projects Included

- **Finance Data Analysis** – Analyzing financial data to identify trends, patterns, transactions, and key financial insights.
- **Retail Data Analysis** – Analyzing retail data to understand sales performance, customer behavior, product trends, and business performance.
- **Healthcare Data Analysis** – Analyzing healthcare data to identify patterns, trends, and insights related to patients, medical records, and healthcare operations.
